# AI 电商行业研究计划

一套可直接执行的 AI 电商行业研究计划，覆盖用户指定的五项要求：

1. **国内外 AI 电商数据（含图表）**——已收集种子数据并产出 7 张样张图表，另规划 11 张（见 `docs/01`）；
2. **双路径覆盖**——站外 2C LLM 种草/导流（豆包、ChatGPT、千问、元宝等）与站内 AI 辅助导购（Rufus、淘宝 AI 万能搜、京言等）均有数据与分析线（见 `docs/01` §1.4/1.5/2.2/2.3）；
3. **MECE 产业链分析**——六层角色框架：代表玩家、动作、成本与收益（见 `docs/02`）；
4. **零售 + 生鲜零售双视角结合点**（见 `docs/03`）；
5. **产品技术/互联网 PM 视角的结合机会**——含原创的「AI 导购评测协议」（见 `docs/04`）。

## 使用方式

- 汇报材料：直接使用 `report/` 下的预读文档与 PPT（当前冻结版 v1.3，已通过三轮独立盲评 ≥4.20 达标线）；
- 研究执行：从 `docs/00_研究计划总览.md` 读起，按 P0–P5 六阶段推进；
- 数据更新：编辑 `data/*.csv` 后运行 `python3 scripts/make_charts.py && python3 scripts/make_pptx.py` 重新生成图表与 PPT；
- 数据纪律：所有数字带三标注（指标口径 / 统计主体 / 影响 vs 成交）+ 置信度分级（高/中/低）；**京东系自报数据按内部研判整体降级为低置信**，规则见 `docs/01` §4 与 `docs/05` §一。

> 数据截至 2026-07；引用他方数据请以原始来源核实为准。
