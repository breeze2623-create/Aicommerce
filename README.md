## 数据分级规则

| 等级 | 定义 | 使用方式 |
|---|---|---|
| P1 公开可追溯 | 第三方监测机构、财报电话会、官方公告、司法文件 | 可作为结论主证据 |
| P2 公司自报 | 财报电话会或官方新闻稿口径的企业自报运营数据 | 须标注「公司口径」并说明归因方法的已知局限 |
| P3 内部口径 | 业务方提供、未公开披露、无第三方交叉验证 | 仅报告内部对照，不与P1混排比较 |
| P4 未采纳 | 存在夸大风险、口径不明或无法交叉验证的自报数据 | 不以任何形式展示；清单见报告附录B |

三项口径纪律：

1. 区分「AI影响的销售」与「AI界面内完成的交易」，二者相差一个数量级以上
2. 区分观察性对比与因果效应，「使用者相对未使用者提升X%」应视为相关性上限
3. 区分实测与测算，测算须标注全部假设与锚点，不得引用为机构预测

## 更新方式

```bash
python3 scripts/make_charts.py   # 重新生成 charts/*.png 与 data/_computed_scenarios.csv
python3 scripts/make_pptx.py     # 重新生成 PPT 与文字稿
```

修改 `data/*.csv` 后重跑上述命令即可。情景测算的中间结果输出至 `data/_computed_scenarios.csv`，可用于复算校验。
