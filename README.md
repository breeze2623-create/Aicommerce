# AI 电商行业研究计划

一套可直接执行的 AI 电商行业研究计划，覆盖用户指定的五项要求：

1. **国内外 AI 电商数据（含图表）**——已收集种子数据并产出 7 张样张图表，另规划 11 张（见 `docs/01`）；
2. **双路径覆盖**——站外 2C LLM 种草/导流（豆包、ChatGPT、千问、元宝等）与站内 AI 辅助导购（Rufus、淘宝 AI 万能搜、京言等）均有数据与分析线（见 `docs/01` §1.4/1.5/2.2/2.3）；
3. **MECE 产业链分析**——六层角色框架：代表玩家、动作、成本与收益（见 `docs/02`）；
4. **零售 + 生鲜零售双视角结合点**（见 `docs/03`）；
5. **产品技术/互联网 PM 视角的结合机会**——含原创的「AI 导购评测协议」（见 `docs/04`）。

## 文件结构

```
docs/
  00_研究计划总览.md        # 主计划：背景、目标、范围、五级能力框架、方法、六阶段执行计划、交付物
  01_市场数据与图表清单.md   # 模块一：国内外种子数据 + 18 张图表规划 + 口径陷阱清单
  02_产业链MECE分析.md      # 模块二：六层产业链角色档案、利益流动、三种竞合模式、待验证假设
  03_零售与生鲜结合点.md     # 模块三：旅程×品类矩阵、生鲜六特征推导、三套组合拳
  04_产品与PM机会地图.md     # 模块四：交互范式、商业化对比、分角色机会清单、评测协议
  05_数据源手册与访谈提纲.md  # 附录：分级数据源、月度监测清单、8~10 场访谈提纲、问卷框架
data/                       # 种子数据底表（CSV，含来源与口径标注）
scripts/make_charts.py      # 图表生成脚本（更新 CSV 后重跑即可刷新图表）
charts/                     # 生成的图表样张（PNG）
```

## 使用方式

- 从 `docs/00_研究计划总览.md` 读起，按 P0–P5 六阶段推进；
- 数据更新：编辑 `data/*.csv` 后运行 `python3 scripts/make_charts.py` 重新生成全部图表；
- 所有数字带三标注纪律（指标口径 / 统计主体 / 影响 vs 成交），见 `docs/01` §4。

> 数据截至 2026-07；引用他方数据请以原始来源核实为准。
